# MyLearnCenter: план стека и структуры

Telegram Mini App + Telegram-бот для пошагового изучения Data Science (в духе Brilliant и Duolingo).

## 1. Стек

| Часть | Выбор | Почему |
|---|---|---|
| Бот | Python, **aiogram 3** | Python близок к Data Science, aiogram — стандарт для Telegram-ботов |
| Backend API | **FastAPI** + SQLAlchemy + Alembic | Один язык с ботом, быстрый, простой |
| База данных | **PostgreSQL** | Надёжно для пользователей, прогресса, тестов |
| Фоновые задачи | APScheduler (позже Redis + arq/Celery) | Напоминания и уведомления по расписанию |
| Mini App (фронт) | **React + TypeScript + Vite**, Tailwind | Быстрый UI, работает внутри Telegram |
| Telegram SDK | `telegram-web-app.js` / `@telegram-apps/sdk` | Тема, кнопки, авторизация через initData |
| 2D-графики | **Plotly.js** (и D3 для особых анимаций) | Интерактивные графики: регрессия, распределения, кластеры |
| 3D | **Three.js** через react-three-fiber | 3D: градиентный спуск по поверхности, PCA, пространство признаков |
| GIF / анимации | GIF/WebP и **Lottie** | Короткие объяснения «на пальцах» |
| Код в браузере (позже) | Pyodide | Студент запускает Python/pandas прямо в уроке |
| AI-помощник | Claude API | Ответы с контекстом текущего урока |
| Деплой | Docker Compose; фронт на Vercel/Netlify, бэкенд на VPS/Railway | Mini App требует HTTPS |

Дневной и ночной режим: берём цвета из `Telegram.WebApp.themeParams`, поэтому приложение само переключается вместе с темой Telegram.

## 2. Роли

- **Администратор (один):** назначает преподавателей, создаёт курсы и группы, видит всю статистику.
- **Преподаватель:** создаёт и редактирует уроки, тесты и задания, проверяет работы студентов своих групп, видит их прогресс.
- **Студент:** проходит уроки, сдаёт тесты и задания, спрашивает AI, получает уведомления.

Роль хранится в базе по `telegram_id`. Первый администратор задаётся через переменную окружения `ADMIN_TG_ID`.

## 3. Структура контента

```
Курс (Data Science)
 └─ Тема / модуль (например, «Статистика», «Линейная регрессия»)
     └─ Урок
         ├─ блоки: теория (Markdown), GIF/Lottie, визуализация, пример кода
         └─ «ворота»: тест ИЛИ задание
```

Блок визуализации хранится как JSON: `{ "widget": "linear-regression-2d", "params": {...} }`. Во фронте есть реестр виджетов, поэтому преподаватель выбирает готовый виджет и задаёт параметры без кода.

Первые виджеты для MVP:
1. `normal-distribution-2d` — ползунки среднего и дисперсии.
2. `linear-regression-2d` — точки и линия, которую можно двигать, с показом ошибки.
3. `gradient-descent-3d` — шарик скатывается по поверхности функции потерь.
4. `kmeans-2d` — кластеры, пошаговая анимация.

## 4. Поток урока и разблокировка

- Все темы видны и открыты сразу (как сказал пользователь).
- Внутри темы уроки идут по порядку: следующий урок открывается, только когда пройден тест или принято задание предыдущего.
- **Тест:** проверяется автоматически, порог прохождения, например, 70%, можно пересдать.
- **Задание:** студент отправляет ответ (текст, файл, ссылку на notebook), преподаватель принимает или возвращает с комментарием.
- Прогресс: XP, серия дней (streak), уровень — как в Duolingo.

## 5. Уведомления (через бота)

- Студенту: ежедневное напоминание о серии, «задание проверено», «новый урок открыт».
- Преподавателю: «новая работа на проверку».
- Всем: рассылка от администратора.
- Время напоминания студент выбирает сам, чтобы учиться днём или ночью.

## 6. AI-помощник

- Кнопка «Спросить AI» в каждом уроке.
- В запрос добавляется теория текущего урока, поэтому ответы идут по теме.
- AI объясняет и даёт подсказки, но не выдаёт готовые ответы на тест.
- Дневной лимит вопросов на студента, история хранится в базе.

## 7. Модель данных (кратко)

`users` (telegram_id, role, name), `groups`, `group_members`, `courses`, `modules`, `lessons`, `lesson_blocks`, `tests`, `questions`, `options`, `test_attempts`, `assignments`, `submissions`, `progress`, `notifications`, `ai_messages`.

## 8. Структура репозитория

```
MyLearnCenter/
├─ backend/
│  ├─ app/api/        # FastAPI роуты
│  ├─ app/bot/        # aiogram: /start, кнопка Mini App, уведомления
│  ├─ app/models/     # SQLAlchemy
│  ├─ app/services/   # прогресс, разблокировка, AI, планировщик
│  └─ alembic/
├─ frontend/
│  ├─ src/pages/      # Каталог, Урок, Тест, Кабинет преподавателя, Админка
│  ├─ src/widgets/    # визуализации 2D/3D
│  └─ src/components/
└─ docker-compose.yml
```

Авторизация: Mini App отправляет `initData`, бэкенд проверяет подпись HMAC токеном бота. Паролей нет.

## 9. Этапы

1. **Каркас:** бот с кнопкой Mini App, авторизация, роли, просмотр тем и уроков (теория + GIF).
2. **Тесты и разблокировка:** тесты, прогресс, открытие следующего урока.
3. **Задания и уведомления:** отправка работ, проверка преподавателем, напоминания.
4. **Визуализации:** первые 4 виджета.
5. **AI-помощник.**
6. **Геймификация:** XP, серии, уровни.
